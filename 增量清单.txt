  旧实现最痛的一点：首启 99-bridge-ready 强写 7 个 uci set wdsdog.main.*，
  把你刷后改的 delay / peer / enabled 全冲回出厂值。这次彻底收口：
    + package/bridge-watchdog/  标准独立插件包（可 apk 单独装卸/升级）
    · 用户配置 /etc/wdsdog.conf【优先级最高】，bridge-watchdog config 生成全注释模板
    · 编译期 wds_delay / wds_peer 默认【留空=不注入】
    · 首启【不再写任何 uci set wdsdog.*】，你的配置不会被覆写
    · 未配置只待命、绝不重启；status 显示配置源
    · 冻结基线 82 项一字不动，只追加 1 项 → 83 项（只增不减）

  刷后自己配：
    bridge-watchdog config                # 生成 /etc/wdsdog.conf（全注释）
    vi /etc/wdsdog.conf                   # 取消注释、填自己的值
    /etc/init.d/bridge-watchdog restart
    bridge-watchdog status                # 看配置源 / 启用 / 距重启还剩

  完整说明：package/bridge-watchdog/files/USER-CONFIG.md

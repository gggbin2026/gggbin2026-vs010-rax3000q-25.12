## 🔴 一、重要事项（标红）

1. 🔴 **铁律：插件 / 服务以【第 51 次】为冻结基线，以后只能【增加或保持】，【不能再减少】。**
2. 🔴 **唯一 LuCI 插件 = luci-app-ttyd；SSH = dropbear；网页终端 = ttyd :7681。这三项删任何一个，编译期与自检都会直接失败。**
3. 🔴 **冻结基线共 82 项（29 编译包 + 4 全局开关 + 9 服务 + 20 工具 + 4 页面 + 4 首启 + 12 关键配置），逐项硬校验。**
4. 🔴 **任何基线项消失 → sh scripts/verify.sh 报「🔴 冻结基线…丢失」并 FAIL；gen-config.sh 在 defconfig 后直接 ::error:: 退出 1，不会产出缺插件的固件。**
5. 🔴 **只允许往 baseline/frozen-baseline.conf【追加行】；禁止删除、改名、改值任何已有行（条目数下限 82 硬编码在 verify.sh，连清单一起删也拦得住）。**
6. 🔴 **防火墙 / IPv6 关闭是红线：属于这版的行为基线，变更需单独显式确认，别顺手打开。**
7. 🔴 **登录 root / admin 是弱密码，刷完第一件事 passwd 改掉（SSH / LuCI / TTYD 同步生效）。**
8. 🔴 **改网桥管理 IP 后必须两台各跑一次 bridge-watchdog resync；虽已用 169.254.241.1/.2 别名保证不会因改 IP 误重启，但互 ping 判据要跟上新地址。**
9. 🔴 **机器狗 WDS 默认启用：连续不通 5 分钟重启；AP 模式停用。刷 AP 不会自动重启。**
10. 🔴 **NTP 默认每 5 分钟循环校时一次（开机先同步一次，之后 sleep 300 无限循环）。**

## 二、冻结规则与三重校验

| 层 | 在哪 | 少了会怎样 |
|---|---|---|
| 自检 | `scripts/verify.sh` 第 52 次判据段 | 逐项比对 82 项，缺一项 → `RESULT: FAIL` |
| 编译期 | `scripts/gen-config.sh` 读同一份清单 | defconfig 后缺包 → `::error::` + `exit 1` |
| 防篡改 | `FROZEN_MIN=82` 硬编码 + 锚点复核 | 连清单一起删行 / 整体替换也会被拦 |

单一数据源：`baseline/frozen-baseline.conf`。**想加插件：在该文件对应段追加一行即可**，verify 会识别为「基线外新增项（允许）」，不阻断；`gen-config.sh` 的必需包清单也自动跟着变。

```text
🔴 冻结基线包缺失（只增不减，禁止精简）： luci-app-ttyd
🔴 冻结基线服务丢失 init.d/nic-guard
🔴 冻结基线被删行：81 项 < 下限 82（只允许追加，禁止删除/改名/改值）
```

# 界面预览截图怎么来的

本轮交付两张 PNG（网桥 / AP），每张左为 1280px 桌面、右为 390px 竖屏，
由 `scripts/render-preview.py` 用 **Chromium + Playwright 真渲染**本仓
`files/www/` 的 HTML/CSS/JS 生成，不是手绘示意图。

- URL：`http://127.0.0.1:<port>/bridge/?demo=1` 与 `/ap/?demo=1`
- `?demo=1` 走 `app.js` 内嵌离线数据（对齐老仓 r29.8 离线预览），**不 fetch 任何 CGI**
- 页面顶部有明确 `DEMO 演示数据` 提示条：数值仅用于展示布局与按钮，**不是实机读数**
- 三页（`/ubnt/` `/bridge/` `/ap/`）共用同一份 `app.js`，所以两张图即可覆盖三页外观

本地复现（需 playwright + chromium）：

```sh
python3 scripts/render-preview.py /data/workspace
```

刷机后去掉 `?demo=1`，页面改读 `/cgi-bin/state` 的真实值；读不到的传感器一律留白「—」，
绝不写假数值。

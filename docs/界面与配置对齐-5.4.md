## 二、配置对齐 + 内核升级修复（重点）

「配置要一样」不等于「值照抄」——5.4 是闭源 QSDK 12.2，6.12 是主线 ath11k/mac80211，
照抄会让 radio 起不来。逐项处理如下：

| 老仓 5.4 QSDK | 本版 6.12 主线 | 判定 |
|---|---|---|
| `htmode=HT160/HT80/HT40`（`qcawifi.sh` 私有约定） | **`HE160/HE80/HE40`** | 🔴 **必须改**：写 HT160 到 6.12 radio 起不来。双白名单（Lua 校验 + shell case）拒绝交叉串写 |
| `ht24=HT40/HT20` | **`HE40/HE20`** | 同上；2.4G 绝不写 HE160/HE80 |
| `db_rssi_thr` / `db_timeout`（弱信号剔除） | 字段保留在 `user.cfg`，后端明确标注**「该基线不支持，不下发」** | 不伪造已生效；页面 ④ / AP 弱信号卡同步标注 |
| QSDK MU-MIMO UCI | 同上，保留字段但不下发 | 6.12 hostapd 无通用 UCI |
| 闭源 `qca_ol/umac/ipq_cnss2` + 单 BDF | `ath11k + mac80211 + wpad-mbedtls` + 官方 `board-2.bin` 容器 | `.ko` 跨内核必挂；ART / BDF 不迁移 |
| `qca-ssdk/swconfig` + 双 GMAC | DSA + 单 `br-lan` 全内网桥 | 25.12 主线绑定 |
| Argon 2.4.3 主题 | **UBNT（仿 UniFi）覆盖层 + 官方 bootstrap 底资源** | 官方 25.12 feed 无 argon；本仓自建 `/luci-static/ubnt`（@import bootstrap 完整资源），真主题目录、零白屏，详见 `docs/主题与UBNT界面.md` |
| `vs010-tick` + `bridge-watchdog`（停用） | **单个 `nwrt-tick`**（procd respawn，dryrun=1） | 老仓"一台机器一个常驻"红线保留 |
| DHCP：AP 可选、WDS 硬禁、`dnsmasq-full` MUST_KEEP | **完全对齐**：`dnsmasq=y`，默认 `ignore=1` + disable；AP 可开、WDS 前端锁定 + 后端二次强制 | 不开时零常驻，符合低占用；不编任何 `luci-app-*` |
| NSS 全链路 MUST_KEEP（QSDK 闭源） | 官方基线无 NSS；`qosmio-25.12-nss` 才追加 5 个加速包 | 默认按你选的"稳定/占用低"；要满速另跑一次 |
| `ppp` / IPv6 / 防火墙全关 | 同样全关（编译期 + 运行期双层） | 一致 |
| WAN/WAN6 删、所有网口内网、STP=1、DHCP Snooping | 全部保留（上一轮已修到真生效） | 一致 |

**没照搬的**（如实）：老仓单包双模式的 `/etc/vs010/` 路径在本版统一为 `/etc/nwrt/`；
老仓 `WDS-Bridge-Z` / `VS010-AP` SSID 按本版出厂命名 `NWRT-WDS` / `NWRT-AP-2G/5G`；
这两项是路径与命名，不是功能差异，需要的话可一行改回。

## 四、边界

- 静态重建 + 本地自检 + 真渲染截图；**没在 Actions 跑 `make`、没实机**。
- `dnsmasq` 是官方 feed 常规包；若所选基线 feed 缺它，`gen-config.sh` 不像 nftables 那样硬停编——
  AP 本机 DHCP 会退回「关闭」，其余功能不受影响（编译日志会如实显示）。
- LuCI `admin` 树控制器依赖 `luci-compat`；未编入时写入页 404，状态页给
  TTYD/SSH 的 `nwrt-apply-config` / `nwrt-apply-mode` 兜底，**不假装能点**。

## 本轮补充：弱信号 / WMM / MU-MIMO 的 6.12 升级修复（替代旧「不下发」口径）

| 5.4 QSDK | 6.12 主线实证 | 判定 |
|---|---|---|
| `db_rssi_thr` / `db_timeout` 弱信号剔除/拒绝 | **`rssi_reject_assoc_rssi` / `rssi_reject_assoc_timeout` / `rssi_ignore_probe_request`**（wifi-device 级真实 UCI → hostapd） | 🔴 不再「不下发」：旧字段禁用，改用主线等价项，AP 模式生效 |
| QSDK 主动踢弱客户端 | `disassoc_low_ack=1`（hostapd 默认）+ `kick_enabled` 走 `iw station del` | 主线无踢人 UCI，用标准 iw + 单常驻分频，默认关 |
| Argon 主题 | UBNT CSS 覆盖层 | 不变 |
| `mu_mimo` / `wmm` 私有开关 | **无独立 UCI**：`wmm_enabled=1` 由 hostapd 硬写；HE 模式硬写 `ieee80211ax=1` + `he_mu_edca_*` | 面板显示「已开启 + 无独立开关」，选关闭明确提示忽略，不伪造 |
| MAC 手填 / 写死 | DTS `nvmem-cells` 从 ART 装配 + `nwrt-mac` 只读展示 | 面板零 MAC 输入框 |

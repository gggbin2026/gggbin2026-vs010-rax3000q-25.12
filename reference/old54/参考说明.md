# 5.4 老仓参考归档

| 文件 | 用途 |
|---|---|
| `ipq5018-rax3000q.dts` / `ipq5018-pz-l8.dts` | OpenWrt main 官方 DTS 还原版，作为本仓 `board/*.6.12.dts` 的基底（已在生成时做最小替换） |

`.ko` / BDF / DTS / 无线脚本都不能直接搬。

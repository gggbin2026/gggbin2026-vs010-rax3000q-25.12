★ 机器狗：改成插件，配置你自己来设置
════════════════════════════════════════
旧实现最痛的一点：首启 99-bridge-ready 强写 7 个 uci set wdsdog.main.*，
把你刷后改的 delay / peer / enabled 全冲回出厂值。这次彻底收口：

  · 新增标准插件包 package/bridge-watchdog/（可 apk 单独装卸 / 升级）
  · 用户配置 /etc/wdsdog.conf 【优先级最高】，bridge-watchdog config 生成全注释模板
  · 编译期 wds_delay / wds_peer 默认【留空 = 不注入】（你主动填才写）
  · 首启【不再写任何 uci set wdsdog.*】，你的配置不会被覆写
  · 未配置 = 只待命、绝不重启；status 显示当前生效的「配置源」

配置优先级：/etc/wdsdog.conf > uci set wdsdog.main.* > 出厂 /etc/config/wdsdog

刷后自己配（3 步）：
  bridge-watchdog config                # 生成 /etc/wdsdog.conf（全注释）
  vi /etc/wdsdog.conf                   # 取消注释、填自己的值
  /etc/init.d/bridge-watchdog restart
  bridge-watchdog status                # 看配置源 / 启用 / 距重启还剩

可调：enabled / delay / grace / interval / iface / peer / anchor /
      mode / max_reboots / dryrun（完整说明见 package/bridge-watchdog/files/USER-CONFIG.md）
原有 CLI 全部保留：set-delay 10 / set-peer auto / set-mode or /
      dryrun on / off / resync / once / status

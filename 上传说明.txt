## 下载后核对（先看大小再解压）

```sh
stat -c %s nwrt-25.12-ubnt.zip       # 对比交付回复里的「精确字节数」
sha256sum nwrt-25.12-ubnt.zip         # 对比交付回复里的「SHA256」
unzip -q nwrt-25.12-ubnt.zip && cd nwrt-25.12-ubnt
sha256sum -c CHECKSUMS.sha256         # 逐文件校验，应全部 OK
sh scripts/verify.sh                  # 应输出 RESULT: PASS
```

包内 `CHECKSUMS.sha256` 排除自身；外层 zip 的大小与 SHA256 以交付回复为准。
以后全量包 / 增量包都按 `交付核对规范.md` 给这 7 项数值。
